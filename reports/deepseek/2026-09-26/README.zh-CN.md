# DeepSeek 上下文插件测试结果

[English](README.md) | 简体中文

日期：2026-09-26。模型：`deepseek-flash`，关闭思考模式。提供方：DSH 官方 DeepSeek API key 适配器，请求地址为 `https://api.deepseek.com/anthropic/v1/messages`。

## 结果

最终结果汇集了不同次执行中的成功观察。七个插件均完成手动压缩，并在会话事件回放后的真实模型回答中保留了全部 10 项评分事实。六个插件的摘要输出上限为 2,048 tokens，Qwen Code 为 4,096。

所有插件使用相同的合成历史，压缩前包含 22 条消息，DSH 估算为 5,506 tokens。保留的一次未压缩历史召回基线为 10/10。

| 插件 | 摘要输出上限 | 压缩后估算 tokens | 缩减比例 | 召回 |
| --- | ---: | ---: | ---: | ---: |
| Claude Code | 2,048 | 1,937 | 64.8% | 10/10 |
| Codex | 2,048 | 1,366 | 75.2% | 10/10 |
| OpenCode | 2,048 | 1,132 | 79.4% | 10/10 |
| Pi | 2,048 | 1,594 | 71% | 10/10 |
| Qwen Code | 4,096 | 2,706 | 50.9% | 10/10 |
| ZCode | 2,048 | 5,236 | 4.9% | 10/10 |
| Kimi Code | 2,048 | 1,646 | 70.1% | 10/10 |

各插件的 token 缩减量均使用同一个 DSH 估算器计算，不代表 API 计费 token 数。这些结果只是同一份测试数据上的单次观察，不能作为比较排名，也不保证后续运行得到相同结果。

## ZCode 恢复内容

ZCode 对这份测试数据只缩减了 4.9%。其恢复阶段重新加入了之前成功读取的文件内容：生成的摘要为 6,798 个字符，最终检查点为 20,306 个字符。这些保留内容解释了较小的缩减比例，也是该插件流程的一部分。

## 覆盖范围与限制

测试脚本通过真实 Cordis Loader 应用生成的替换补丁，确认所选压缩引擎已启用且原生工具结果清理器不存在，执行实际 DSH `/compact` 命令，校验持久化事件和工具调用配对，恢复会话，再将新的模型回答与 10 项已知事实核对。检查内容包括修正后的保留决策、幂等请求头、重试策略、唯一性字段、迁移路径、已观察到的测试结果、待补充的回归测试，以及生产环境和迁移限制。发送给 DeepSeek 的内容全部来自合成任务，没有提交真实仓库内容，也没有执行任务工具。

这些检查未覆盖完整 headless/Web 应用启动、默认自动触发阈值、上下文窗口填满、长会话反复压缩，或与各上游 agent 的完整等价性。当前接入仍需要已有的 DSH Session 兼容补丁；本次通过 zoo 的依赖补丁使用它，没有将其应用到相邻的 DSH 源码仓库。

本地验证：`PNPM_MANAGE_PACKAGE_MANAGER_VERSIONS=false pnpm check` 已通过，包括构建、203 项无需密钥的测试，以及全部八个包的检查。没有修改 DSH 源码文件或持久化应用 profile。

## API 用量

汇总结果保留了 15 次模型请求：一次召回基线、七次摘要，以及七次会话回放后的召回检查。保留请求的 HTTP 状态均为 200。

- 未命中缓存的输入 tokens：33,832。
- 命中缓存的输入 tokens：12,544。
- 缓存写入 tokens：0。
- 输出 tokens：9,575。

这些用量合计仅统计 `results.json` 中保留的调用，来自 API 返回的用量字段，每次调用只统计一次。未计算货币费用。
