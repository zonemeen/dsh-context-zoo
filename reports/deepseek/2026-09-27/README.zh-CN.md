# Cline DeepSeek 实际 API 测试结果

[English](README.md) | 简体中文

日期：2026-09-27。模型：`deepseek-flash`，关闭思考模式。提供方：DSH 官方 DeepSeek API key 适配器，请求地址为 `https://api.deepseek.com/anthropic/v1/messages`。

## 结果

Cline 完成手动压缩，从会话事件恢复后，新的模型回答保留了全部 10 项被检查事实。压缩前的基线召回同样为 10/10。

| 插件 | 摘要输出上限 | 压缩前估算 tokens | 压缩后估算 tokens | 缩减比例 | 恢复后召回 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Cline | 2,048 | 5,506 | 1,844 | 66.5% | 10/10 |

一次摘要请求正常结束，输出使用 1,132 tokens。压缩耗时 4.94 秒，完整检查耗时 7.345 秒。三次 HTTP 请求全部返回 200，分别用于基线召回、压缩摘要和恢复后召回。

配置为 `auto: false`、`keepRecentTokens: 256`、`maxSummaryTokens: 2048`、`maxSummaryAttempts: 1`、`maxOverflowRetries: 0`。256-token 保留量是本次测试设置，插件默认值为 20,000 tokens。

缩减比例使用 DSH token 估算器计算，不等于 API 计费 token 的变化。这是单个合成样本的一次观察；此前的[七插件报告](../2026-09-26/README.zh-CN.md)仍保留各自运行结果。

## 覆盖范围与限制

测试通过真实 Cordis Loader 加载生成的 profile 覆盖补丁，确认所选压缩引擎已启用且原生工具结果清理器未启用，然后调用 DSH `/compact`。测试检查受保护指令和工具调用配对，验证持久化事件，恢复会话，再将新的模型回答与 10 项已知事实核对。

事实包括最终 48 小时保留决策、幂等请求头、重试状态与次数及间隔、租户维度唯一性、迁移路径、已观察到的本地测试结果、待补充的租户隔离回归测试，以及生产访问和迁移限制。发送到 API 的内容全部来自合成对话，没有执行任务工具。

本次检查覆盖手动模型摘要及恢复后召回，不覆盖默认自动阈值、实际上下文溢出、无需模型调用的回退、长会话行为或完整 headless/Web 应用启动。自动阈值、溢出处理和 profile 覆盖补丁另有本地测试，不能据此推断完整应用启动或长会话表现。

缓存写入 tokens 为 0。以上为提供方报告的用量，三次请求各计入一次；未计算货币费用。

## 复现

在 Git 忽略的 `.env.local` 中配置 `DEEPSEEK_API_KEY`，然后从仓库根目录运行：

```sh
node --env-file=.env.local scripts/check-deepseek.mjs --agent cline
```

由 Node 显式加载本地环境文件。报告、记录的会话数据和 DSH profile 均不包含 key。[results.json](results.json) 保存完整观察结果，包括配置、请求状态、模型输出和各项事实评分。
